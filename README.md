# Portfolio - Radek Šmiga

Osobní prezentační web s portfoliem, životopisem a kontaktními informacemi.

## O projektu

Tyto stránky slouží jako osobní prezentace a profesní portfolio. Najdete zde informace o mých zkušenostech, vzdělání a způsoby, jak mě kontaktovat.

## Obsah stránek

- **Úvodní sekce** - krátké představení
- **O mně** - osobní příběh a zájmy
- **CV** - pracovní zkušenosti
- **Vzdělání** - přehled studia
- **Certifikace** - získané certifikáty
- **Kontakt** - způsoby spojení

## Technologie

Web je postaven pomocí:

- **Astro** - moderní framework pro rychlé webové stránky
- **Tailwind CSS** - stylování
- **TypeScript** - programovací jazyk

## Jak spustit lokálně

Pokud chcete projekt vyzkoušet lokálně:

```bash
# Klonování repositáře
git clone https://github.com/smigarad/portfolio_pages.git
cd portfolio_pages

# Instalace závislostí
npm install

# Spuštění vývojového serveru
npm run dev
```

Web poběží na adrese http://localhost:4321
